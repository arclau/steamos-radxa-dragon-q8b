# steamos/tools — vendored tools

## extract_rootfs.py

Rebuilds the official SteamOS ARM (Steam Frame / Deckard) aarch64 `rootfs.img`
from Valve's RAUC + casync store. Device-independent: it only reconstructs
Valve's image and verifies it against a SHA256.

- **Upstream**: https://github.com/hashtagbasit/SteamOS-ARM-Handhelds
  (`scripts/extract_rootfs.py`)
- **License**: GPL-2.0 (that repository's original software/scripts are GPL-2.0;
  see its `LICENSE`). Vendored here unmodified.
- **Vendored verbatim** so its SHA256 stays verifiable:
  `sha256 = f6e5840a6d14b08b026e20442ab4597af1d780bb779fea91cdd8c11fe2ffb378`
- **Do not edit this file.** If it must change, re-vendor and update
  `upstream.lock` + this checksum in the same commit.

**Runtime deps**: `python3` with `requests` and `zstandard`; the caller also
needs `unsquashfs` (squashfs-tools) to unpack the `.raucb` into `rootfs.img.caibx`.
The build entrypoint for this is `scripts/fetch-valve-rootfs.sh`.

Note: the script's built-in default build pin and `EXPECTED_SHA256` are
**stale** — we always override them from the pinned build in `upstream.lock`
(the SHA comes from Valve's own `manifest.raucm`), exactly as the upstream
`make-steamos-sm8650.sh` driver does.
